# Tetra Official Website ([mgu-tetra.github.io](https://mgu-tetra.github.io/))

明治学院大学のサークル **Tetra (テトラ)** の公式ウェブサイトのソースコードです。
本サイトは HTML, CSS, JavaScript (Vanilla JS) のシンプルな構成で作成されており、GitHub Pages にてホスティングされています。

---

## 🚀 プロジェクト概要 (Project Overview)

Tetra は主に以下の2つの部門で活動しています。

- **Programming 部門**: Web アプリ開発、モバイルアプリ開発、ゲーム制作 (Unity 等)、AI 研究など
- **Graphics 部門**: 3D CG (Blender)、デザイン (Figma/Illustrator)、映像制作 (After Effects/Premiere Pro)、プロジェクションマッピングなど

本リポジトリは、サークルの紹介、活動実績の展示、およびお知らせ (News) の配信を行うための静的ウェブサイトです。

---


## 📰 ニュース配信システム (Headless News CMS)

本サイトには、外部のデータベースやサーバーを必要としない **サーバーレス/ヘッドレス型のニュース配信システム** が組み込まれています。
